Esta es la personalización de una aplicación en la que estuve trabajando

Es para crear un ranking ayudándonos con un formato round robin donde podemos reportar los resultados de las partidas tanto como usuario como administrador

Como administrador podemos rechazar o aceptar solicitudes para participar en el ranking, reportar y editar resultados, agregar o eliminar jugadores

Como usuario puedes ver tus sets faltantes, la lista de todos los jugadores, tu historial de partidas y el historial de los demás 

Se puede consultar el calendario para revisar qué eventos pendientes se tienen para ese día, como torneos o peleas por equipos
